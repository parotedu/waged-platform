# منصة واجد (Waged by Parot) 🛡️

> المنصة الذكية للتواصل الفوري والآمن والمجهول عبر رموز QR دون كشف أرقام الهواتف أو الهوية — أحد منتجات **PAROT Corp**.

---

## 🌟 المميزات الأساسية
- **حماية الخصوصية 100% (Zero-PII):** تواصل مع من يجد مقتنياتك أو يواجه مشكلة مع ركنة سيارتك دون مشاركة رقم هاتفك أو بريدك الإلكتروني.
- **الموقع الجغرافي (GPS) التفاعلي:** إرسال موقع المسح الجغرافي على خرائط Google Maps بموافقة الزائر.
- **تنبيهات تليجرام الفورية + Webhook:** ربط تلقائي بضغطة زر عبر `/start` أو عبر Chat ID، بالإضافة لدعم Webhooks للواتساب وأنظمة الأتمتة.
- **وضع المفقودات (Lost Mode):** تفعيل تنبيه عاجل يظهر فوراً عند مسح رمز الغرض المفقود.
- **استوديو طباعة الملصقات (Print Studio):** تصميم وطباعة ملصقات Vector دقيقة للسيارات، اللابتوب، الحقائب، والمفاتيح.
- **نظام الاشتراكات والباقات:** باقة مجانية، احترافية (Pro)، وباقة الأعمال والأساطيل مع تتبع الاستخدام والفواتير.
- **تصميم مزدوج (Midnight Glass + Light Mode) و PWA:** واجهة متجاوبة بالكامل قابلة للتثبيت على الهواتف.

## 🚀 التشغيل المحلي (Local Setup)

```bash
npm install
cp .env.example .env
npm start
```
ثم افتح المتصفح على: `http://localhost:4000`

لتشغيل الاختبارات الشاملة:
```bash
npm test
```

## ☁️ النشر على منصة Render (خطوات الربط مع GitHub)

المشروع مجهز بالكامل للنشر عبر ملف `render.yaml` Blueprint:

1. **اربط مستودع GitHub على Render:**
   - ادخل إلى [dashboard.render.com](https://dashboard.render.com) → **New +** → **Blueprint** (أو **Web Service**).
   - اختر مستودع `parotedu/waged-platform`.
2. **إعدادات الخدمة (تُقرأ تلقائياً من `render.yaml`):**
   - **Runtime:** `Node`
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Health Check Path:** `/api/health`
3. **متغيرات البيئة (Environment Variables):**
   - `NODE_ENV` = `production`
   - `JWT_SECRET` = (يُنشأ تلقائياً عبر Render أو أدخل مفتاحاً طويلاً عشوائياً)
   - `TELEGRAM_BOT_TOKEN` = توكن البوت من `@BotFather` (اختياري لتفعيل تنبيهات تليجرام الحقيقية)
   - `TELEGRAM_BOT_USERNAME` = معرف البوت بدون `@` (مثال: `WagedParotBot`)
   - *ملاحظة:* المنصة تقرأ `RENDER_EXTERNAL_URL` تلقائياً، لذا ستعمل روابط تليجرام ورموز الـ QR على الدومين الفعلي دون أي تعديل يدوي.
4. **حفظ قاعدة البيانات الدائم (هام لبيئة الإنتاج):**
   - على خطة Render Free يتم إعادة تعيين القرص المحلي عند كل Deploy جديد.
   - لحفظ بيانات المستخدمين ورموز الـ QR بشكل دائم على Render: اختر خطة **Starter** وأضف **Persistent Disk** على المسار `/var/data` ثم أضف متغير البيئة `DATA_DIR=/var/data`.
