# منصة واجد (Waged)

> المنصة الذكية للتواصل الفوري والآمن والمجهول عبر رموز QR دون كشف أرقام الهواتف أو الهوية.

---

## المميزات الأساسية
- **حماية الخصوصية 100% (Zero-PII):** تواصل مع من يجد مقتنياتك أو يواجه مشكلة مع ركنة سيارتك دون مشاركة رقم هاتفك أو بريدك الإلكتروني.
- **الموقع الجغرافي (GPS) التفاعلي:** إرسال موقع المسح الجغرافي على خرائط Google Maps بضغطة زر.
- **تنبيهات تليجرام الفورية + Webhook:** ربط تلقائي عبر `/start` أو عبر Chat ID، ودعم Webhooks.
- **نظام اشتراكات بالدفع عبر إنستا باي (InstaPay):**
  - التحويل على رقم `01557527365` وإرسال إشعار التحويل من لوحة المستخدم، ليتم التأكد والتفعيل خلال 24 ساعة.
- **لوحة تحكم مخصصة للتفعيل (`/admin.html`):**
  - مخصصة للحساب الرئيسي (`super_admin`) لمراجعة طلبات إنستا باي وتفعيل الحسابات، مع إمكانية إضافة وإدارة مسؤولين مساعدين (`admin`) لتفعيل الحسابات معه.
- **دعم مزدوج لقواعد البيانات:** يعمل محلياً عبر **SQLite**، ويتصل تلقائياً بـ **PostgreSQL** عند توفير `DATABASE_URL` في الإنتاج (Render).

---

## التشغيل المحلي

```bash
npm install
cp .env.example .env
npm start
```
- رابط المنصة: `http://localhost:4000`
- لوحة تفعيل الحسابات: `http://localhost:4000/admin.html`
- بيانات الحساب الرئيسي الافتراضية (تُعدّل من `.env`):
  - البريد: `admin@waged.app`
  - كلمة المرور: `WagedAdmin@2026!`

لتشغيل الاختبارات الشاملة:
```bash
npm test
```

## النشر على Render وربطه بقاعدة بيانات PostgreSQL

المشروع مجهز بملف `render.yaml` متكامل (يشمل خدمة الويب + قاعدة بيانات PostgreSQL):
1. ادفع التحديثات إلى GitHub (`git push origin main`).
2. في Render اختر **New + → Blueprint** واربطه بمستودع `parotedu/waged-platform`.
3. سينشئ Render قاعدة بيانات `waged-db` (PostgreSQL) ويربط `DATABASE_URL` و`JWT_SECRET` و`INSTAPAY_NUMBER=01557527365` تلقائياً.
4. أضف `SUPER_ADMIN_PASSWORD` القوية في متغيرات البيئة (و`TELEGRAM_BOT_TOKEN` و`TELEGRAM_BOT_USERNAME` إن أردت تفعيل بوت تليجرام).
